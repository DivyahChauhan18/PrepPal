# PrepPal 🎙

An AI-powered interview coach that helps job seekers and HR professionals prepare for interviews with tailored questions, model answers, and honest spoken feedback.

## What it does

- **Question Generation** — Paste any job description and get 8-10 tailored interview questions across Behavioural, Technical, Situational, and Culture Fit categories
- **Model Answers** — Each question comes with what interviewers are looking for, a model answer approach, and red flags to avoid
- **Voice Practice** — Speak your answer using the built-in microphone instead of typing — just like a real interview
- **AI Feedback** — Get a score out of 10, specific strengths, improvements, missing points, and a suggested better answer

## Built with

- React
- Anthropic Claude API (claude-sonnet-4-5)
- Web Speech API (browser-native speech recognition)

## How to run locally

1. Clone the repo
2. Run `npm install`
3. Create a `.env` file in the root with: `REACT_APP_API_KEY=your-anthropic-key`
4. Run `npm start`
5. Open `http://localhost:3000`
